## 🛠 How to Run the Code

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/leetcode-solutions.git
   ```

2. Navigate to the project:
   ```bash
   cd leetcode-solutions
   ```

3. Compile a Java file:
   ```bash
   javac easy/TwoSum.java
   ```

4. Run the program:
   ```bash
   java easy.TwoSum
   ```
